Layout avancé

Grid

système de mise en page bidimensionnel qui permet de créer des mises en page complexes et réactives avec une grande flexibilité. 


.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 colonnes de même taille */
  grid-template-rows: repeat(2, 1fr); /* 2 lignes de même taille */
  gap: 10px;
}
/*fr : fraction*/

Subgrid

système de mise en page bidimensionnel qui permet de créer des mises en page complexes et réactives avec une grande flexibilité. 


              .container {
                display: grid;
                grid-template-columns: repeat(3, 1fr); /* 3 colonnes de même taille */
                grid-template-rows: repeat(2, 1fr); /* 2 lignes de même taille */
                gap: 10px;
              }
              /*fr : fraction*/
              .item {
                grid-column: 1fr;
                grid-template-row: subgrid;
                grid-row: 1/2;
              }

Container query

Les requêtes de conteneur permettent d'appliquer des styles CSS en fonction de la taille d'un conteneur parent plutôt que de la fenêtre d'affichage. 


.container {
  width: 100%;
  height: 100%;
  padding: 20px;
  background-color: lightblue;
}
.itmem {
  display: flex;
  flex-direction: column;
}
@container (min-width: 500px) {
  .item {
   flex-direction: row;
  }

Flexbox

Flexbox est un modèle de mise en page unidimensionnel qui permet de disposer des éléments dans une direction (ligne ou colonne) et de gérer leur alignement et leur espacement. 


.container {
  display: flex;
  flex-direction: row; /* ou column */
  justify-content: center; /* aligne les éléments horizontalement */
  align-items: center; /* aligne les éléments verticalement */
  gap: 10px; /* espace entre les éléments */
}
.item {
  flex: 1; /* prend tout l'espace disponible */
  min-width: 100px; /* largeur minimale */
  max-width: 300px; /* largeur maximale */
}

Variables CSS

Les variables CSS (ou propriétés personnalisées) sont des valeurs définies par l'utilisateur qui peuvent être utilisées dans le CSS pour stocker des valeurs réutilisables. 


:root {
  --main-color: #3498db; /* couleur principale */
  --secondary-color: #2ecc71; /* couleur secondaire */
  --font-size: 16px; /* taille de police */
}
  
.button {
  background-color: var(--main-color); /* utilise la variable */
}

Techniques d’animations

Transform

Transform permet de déplacer, faire pivoter, redimensionner un élément

Il est possible de combiner plusieurs transformations

exemple : 

.element {
  translate: 50px, 100px;
  rotate: 45deg;
  scale: 1.2;
  transform: skew(10deg, 20deg);
}
/* ou */
.element {
  transform: translate(50px, 100px) rotate(45deg) scale(1.2) 
  skew(10deg, 20deg);
}

Techniques d’animations

Transform

Il est possible de combiner plusieurs transformations

exemple : 

.element {
  transition: transform 0.5s ease-in-out;
}
.element:hover {
  transform: translate(50px, 100px) rotate(45deg) scale(1.2) 
  skew(10deg, 20deg);
}
